# Conciliador automático de cheques electrónicos (ECHEQ)

Proyecto en desarrollo que reemplaza el comparador nutricional por pedido de la
usuaria. Titular: cuenta GitHub `emilialevi2008-pixel`; desarrollo asistido por Codex.
Ver PLAN_TP2.md para alcance, etapas y decisiones de cálculo. El tema propio
requiere aprobación de la cátedra; no está confirmada.

El programa será de consola, con datos sintéticos CSV/JSON y cuatro reportes;
no usará web, base de datos ni conexiones bancarias reales.
